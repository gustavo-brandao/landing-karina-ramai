# Landing Page — Karina Ramai Arquitetura

Landing page institucional desenvolvida para a arquiteta **Karina Ramai**, com foco em apresentação profissional, identidade visual autoral e uma experiência visual elegante e funcional.

O projeto foi concebido para ser leve, responsivo e de fácil manutenção, atendendo às necessidades de divulgação de serviços, portfólio e contato profissional.

---

## 📌 Tecnologias utilizadas

- HTML5  
- Tailwind CSS (via CDN)  
- CSS customizado para identidade visual  
- JavaScript (interações e animações leves)  
- GitHub Pages (hospedagem)

---

## 📂 Estrutura do projeto

```text
/
├── index.html
├── Imagens/
│   └── carina__ramai.png
├── assets/
└── js/
```

## ✨ Características

- Layout responsivo (desktop e mobile)
- Identidade visual alinhada à marca
- Seções institucionais e portfólio
- Animações suaves e não invasivas
- Código simples, organizado e de fácil manutenção

## 🤖 Desenvolvimento assistido por IA

Este projeto foi desenvolvido com o apoio de ferramentas de Inteligência Artificial.
A estrutura base e organização do código foram criadas com auxílio do ChatGPT, enquanto ajustes visuais, estilos e refinamentos pontuais contaram com o suporte do GitHub Copilot, sempre com validação, revisão e curadoria manual.
