# Landing Page — Karina Ramai Arquitetura

Landing page institucional desenvolvida para a arquiteta **Karina Ramai**, com foco em apresentação profissional, identidade visual autoral e experiência visual elegante.

O projeto foi pensado para ser leve, responsivo e de fácil manutenção, ideal para divulgação de serviços, portfólio e contato profissional.

---

## 📌 Tecnologias utilizadas

- HTML5
- Tailwind CSS (via CDN)
- CSS customizado para identidade visual
- JavaScript (interações e animações leves)
- GitHub Pages (hospedagem)

## Características

- Layout responsivo (desktop e mobile)
- Identidade visual alinhada à marca
- Seções institucionais e portfólio
- Animações suaves e não invasivas
- Código simples e organizado
